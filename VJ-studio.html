启动真实识别服务

真实识别需要本地 Node.js 服务来转发 API 请求。直接双击 HTML 时不能启动服务，也不能上传音频识别。

操作步骤：

1. 安装 Node.js LTS：nodejs.org/en/download

2. 打开终端（Windows 使用 PowerShell），输入：

cd "解压后的文件夹完整路径"

3. 进入文件夹后运行：npm start

4. 终端显示 VJ Studio running at... 后，打开：

http://127.0.0.1:8088/

5. 在新页面选择「上传音频」→「方式一：真实识别」。原来的文件页面不能继续使用，也不需要刷新。

快捷脚本：macOS 用 .command，Windows 用 .bat。

如果系统提示“无法验证开发者 / 发布者”或“可能有风险”，请关闭提示，改用上面的 npm start 方式启动。
